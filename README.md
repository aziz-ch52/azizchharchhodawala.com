Personal portfolio website for **Aziz Chharchhodawala**, an aspiring Data Analyst (BCA, Sigma University, Vadodara) working with Python, SQL, Excel and Power BI.

**Live site:** https://aziz-ch52.github.io/azizchharchhodawala.com/
<br>
**GitHub:** https://github.com/aziz-ch52
<br>
**LinkedIn:** https://www.linkedin.com/in/aziz-chharchhodawala
